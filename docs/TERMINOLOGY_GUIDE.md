# SAVEN Core — Terminology Guide

**Status:** Active  
**Date:** 2026-07-24  
**Authority:** Language, Navigation and Footer Refinement sprint

---

## 1. Principle

One term = one meaning. Prefer simple, natural English. Avoid synonym clusters that confuse readers.

---

## 2. Preferred public terms

| Prefer | Avoid / limit |
|--------|----------------|
| Main topics | Major domains |
| Topic / Topic area | Domain (in UI chrome) |
| What this covers | Current scope |
| What comes next | Future scope |
| Notes | Engineering notes |
| Related concepts | Concept dependencies |
| Document information | Knowledge passport / engineering metadata |
| Suggested reading | Reading path |
| Status | Current maturity (as a separate UI label) |
| Document / Topic / Page | Knowledge Object (except where the technical layer requires it) |
| Open | Explore / Launch (for simple CTAs) |
| People | Human (when introducing the architecture chain to general readers) |

Product and system names stay stable: **SAVEN Core**, **Human Data**, **Human Data Model**, **Knowledge Engine**, **Safety Layer**, and related published titles.

---

## 3. Domain names (stable)

Use these exact public domain names:

- Technology
- Systems
- Applications
- Trust
- Research

Purpose and Foundation remain published pages, surfaced mainly from the footer and About/Resources groups — not as primary top-nav items.

---

## 4. Status language

Honest development language only:

- Complete
- In progress
- Planned

Do not imply Operational, Clinical, or Validated status unless explicitly assigned later.

---

## 5. Words to avoid in public prose

Unless truly necessary and factual:

comprehensive · cutting-edge · state-of-the-art · next-generation · advanced · innovative · groundbreaking · revolutionary · world-class

---

## 6. Writing style

- Short sentences
- One idea per paragraph
- No buzzwords
- No exaggerated claims
- No unnecessary repetition
- Explain ideas in ordinary language for healthcare professionals, engineers, researchers, investors, business leaders, and educated general readers
